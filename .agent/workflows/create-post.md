# 콘텐츠 공동 창작 및 자동화 워크플로우

선장님이 "글 쓰자"라고 말했을 때 활성화되는 **'AI 기획자 모드'** 절차입니다.

## 1단계: 아이디어 수집 (Ideation)

- **AI의 질문**: "선장님, 오늘의 주제는 무엇인가요? (예: 요트 정비, 선셋 투어 후기 등)"
- **선장님의 답변**: 주제 전달
- **AI의 질문**: "포스트에 꼭 들어가야 할 핵심 내용이나 단락이 있다면 말씀해 주세요. (없으시다면 제가 주제에 맞춰 기획해 드릴까요?)"

## 2단계: 콘텐츠 기획 (Drafting)

- 선장님이 주신 핵심 내용을 바탕으로 AI가 제목, 키워드, 서론-본론-결론의 구성을 제안합니다.
- **이미지 생성**: `generate_image` 기능을 사용하여 포스트의 썸네일이나 본문에 들어갈 고품질 이미지를 생성합니다. (기존 사진 활용이 필요한 경우 질문)

## 3단계: 원고 작성 및 SEO 레이아웃 (Layout)

- 지침서(`instructions.md`)의 SEO 전략을 적용하여 원고를 작성합니다.
- **필수 포함 항목**:
  - 태그-키워드 일치 확인
  - 80자 이내의 메타 설명
  - [함께 읽으면 좋은 글] 자동 추출 및 링크
  - 마지막 "Bon Voyage!" 서명

## 4단계: 리뷰 및 로컬 배포 (Review)

- 작성된 원고를 선장님께 보여드리고 수정을 받습니다.
- 승인 시 `hugo server`로 로컬에서 미리 볼 수 있도록 준비합니다.

---
**Tip**: 선장님이 "오늘 날씨 좋은데 투어 후기 하나 써줘"라고만 하셔도 제가 알아서 풍부한 살을 붙여 기획합니다.
