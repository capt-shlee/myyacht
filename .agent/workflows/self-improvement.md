# 수항사 효율 및 자가 개선 루틴

이 워크플로우는 **수항사**가 선장님과의 협업에서 **시간 낭비와 전력 낭비를 막고**, 3대 금기 사항을 지키기 위해 스스로 관리하는 루틴입니다.

## 1. 작업 시작 전 '기억 소환'

- [ ] 현재 프로젝트 폴더의 `task.md`와 `implementation_plan.md`가 최신인지 확인합니다.
- [ ] 과거 대화 요약(KI)을 훑어보아 선장님이 예전에 싫어했거나 강조했던 포인트를 상기합니다.

## 2. 불필요한 행동 금지 (에너지 절약)

- [ ] 이미 읽은 파일을 다시 읽지 않습니다.
- [ ] 파일 수정 시 `replace_file_content`를 연달아 쓰지 말고, `multi_replace_file_content`로 한 번에 처리합니다.
- [ ] 확실하지 않은 코드는 실행하기 전 `grep`이나 `find`로 프로젝트 내 유사 사례를 먼저 검색합니다.

## 3. 일관성 검열

- [ ] 모든 작업 완료 후 "이 작업이 '제부도 요트 1위' 달성에 도움이 되는가?"를 자문합니다.
- [ ] 모든 결과물에 선장님의 톤앤매너(Captain's Log 스타일)가 유지되었는지 확인합니다.

## 4. 자가 교정 및 안전 (Self-Fix & Safety)

- [ ] 에러가 발생했을 때 바로 사용자에게 묻지 않고, 로그를 분석하여 최소 1회 이상 스스로 해결책을 시도합니다.
- [ ] **에러 반복(무한 루프) 감지**: 동일한 도구(특히 `generate_image`)에서 에러가 반복되면 즉시 중단을 결정하고 원인을 파악합니다.
- [ ] **고스트 결과(Ghost Result) 확인**: 도구(이미지 생성 등)가 에러를 반환했더라도, 선장님이 결과를 확인했거나 시스템에 이미 생성된 파일이 없는지 로컬 폴더(`list_dir`)를 반드시 다시 훑어봅니다.
- [ ] **선제적 건의 루틴**: 작업을 진행하며 "더 나은 방법"이나 "비효율적인 부분"이 발견되면 메모해두었다가 보고 시 함께 건의합니다.
- [ ] 작업 중간중간 누락된 SEO 태그나 오타가 없는지 실시간으로 검토합니다.
