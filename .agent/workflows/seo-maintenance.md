# SEO 유지보수 및 오류 방지 워크플로우

선장님의 블로그가 구글 서치 콘솔(Google Search Console)과 네이버 서치 어드바이저(Search Advisor)에서 **항상 "우수" 상태를 유지**하도록 하기 위한 체크리스트입니다.

## 1. 태그 표준화 원칙 (중복 콘텐츠 방지)

구글은 비슷한 이름의 태그 페이지가 너무 많으면 "콘텐츠가 부족한 중복 페이지"로 판단하여 색인에서 제외합니다. 다음 매핑 규칙을 반드시 준수하세요.

### 핵심 키워드 통합 규칙

- **제부도 투어**: `제부도 요트`, `전곡항 요트` 등을 쓰지 말고 **`제부도요트투어`** 하나로 통일합니다.
- **항해 기술**: 영어(`anchoring`) 대신 한글 **`앵커링`**을 사용하고, 복잡한 용어는 **`선장노하우`**로 묶습니다.
- **엔지니어링**: 자잘한 부품명 대신 **`엔진정비`**, **`요트전력관리`**, **`오픈소스항해`** 등 상위 개념 태그를 사용합니다.
- **에세이**: 선장님의 개인적인 이야기는 **`선장일기`** 태그를 사용합니다.

## 2. 404 오류 방지 및 경로 관리

검색 엔진 봇이 잘못된 경로를 타지 않도록 관리합니다.

- **robots.txt 확인**: 새로운 404 오류가 리포트되면 즉시 `static/robots.txt`에 해당 경로를 `Disallow` 추가합니다. (예: `/HOME`, `/contact` 등)
- **전용 금기 사항**: 절대 `localhost` 주소가 포함된 링크를 배포하지 마세요.
- **Sitemap 갱신**: 태그를 대대적으로 수정한 후에는 `hugo` 빌드를 통해 `sitemap.xml`이 최신화되었는지 확인합니다.

## 3. 정기 점검 가이드 (Search Console & Advisor)

1. **서치 콘솔 분석**: '색인이 생성되지 않음' 리스트를 확인하고, '태그(/tags/)' 관련 URL이 많다면 즉시 태그 통합 작업을 수행합니다.
2. **서치 어드바이저 검사**: 네이버에서 '설명(Description)이 너무 김' 오류가 나오면 80자 이내로 즉시 줄입니다.
3. **URL 검사 도구 활용**: 핵심 포스트를 수정했다면 구글 서치 콘솔의 'URL 검사' 도구에서 '색인 생성 요청'을 직접 클릭합니다.

## 4. 포스트 작성 시 SEO 체크리스트

- [ ] **태그 개수**: 태그는 포스트당 3~5개 이내로 제한합니다. (너무 많으면 색인 품질 저하)
- [ ] **메타 데이터**: `description`에 포스트 핵심 내용을 요약하고, 핵심 키워드는 첫 문장에 포함합니다.
- [ ] **이미지 Alt**: 모든 이미지에는 `alt` 속성을 넣어 구글 이미지 검색에 노출되게 합니다. (예: `alt: "볼보펜타 엔진오일 교환 장면"`)
