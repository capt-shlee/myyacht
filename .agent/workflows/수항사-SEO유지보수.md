# SEO 유지보수 및 오류 방지 워크플로우

선장님의 블로그가 구글 서치 콘솔(Google Search Console)과 네이버 서치 어드바이저(Search Advisor)에서 **항상 "우수" 상태를 유지**하도록 하기 위한 체크리스트입니다.

## 1. 404 오류 방지 및 경로 관리 (태그 비활성화 대응)

구글은 비슷한 이름의 태그 페이지가 너무 많으면 "콘텐츠가 부족한 중복 페이지"로 판단하여 색인에서 제외합니다. 현재 사이트에서는 **`tags` 기능을 완전히 비활성화**했으므로, 다음 관리 원칙을 준수하세요.

- **tags 관련 404 대응**: `tags` 페이지가 더 이상 생성되지 않으므로, 기존 인덱싱된 `/tags/` 경로에서 404 오류가 발생할 수 있습니다. 이 경우 **404 유지 + 검색제외 요청**을 기본으로 합니다. (robots.txt로 전체 차단하지 않음)
- **전용 금기 사항**: 절대 `localhost` 주소가 포함된 링크를 배포하지 마세요.
- **Sitemap 갱신**: 핵심 설정을 변경한 후에는 `hugo` 빌드를 통해 `sitemap.xml`이 최신화되었는지 확인합니다.

## 2. 정기 점검 가이드 (Search Console & Advisor)

1. **서치 콘솔 분석**: '색인이 생성되지 않음' 리스트를 확인하고, 기존 `tags` 관련 URL이 리스트에 있다면 '검색 제외 요청' 등을 통해 정리합니다.
2. **서치 어드바이저 검사**: 네이버에서 '설명(Description)이 너무 김' 오류가 나오면 80자 이내로 즉시 줄입니다.
3. **URL 검사 도구 활용**: 핵심 포스트를 수정했다면 구글 서치 콘솔의 'URL 검사' 도구에서 '색인 생성 요청'을 직접 클릭합니다.

## 3. 포스트 작성 시 SEO 체크리스트

- [ ] **태그 제거 확인**: 프런트매터에 `tags:` 필드가 존재하지 않는지 확인합니다. (완전 제거 필수)
- [ ] **카테고리 활용**: 분류가 필요한 경우 `categories` 필드를 사용합니다.
- [ ] **메타 데이터**: `description`에 포스트 핵심 내용을 요약하고, 핵심 키워드는 첫 문장에 포함합니다.
- [ ] **이미지 Alt**: 모든 이미지에는 `alt` 속성을 넣어 구글 이미지 검색에 노출되게 합니다. (예: `alt: "볼보펜타 엔진오일 교환 장면"`)
