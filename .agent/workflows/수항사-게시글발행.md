# 블로그 게시글 작성 및 SEO 검수 워크플로우

이 문서는 수항사가 포스트 발행 시 반복해야 하는 표준 절차입니다.

## 0단계: 실행 원칙

- 선장님이 명시적으로 "배포해"라고 지시하기 전에는 배포하지 않습니다.
- 삭제된 URL 정책은 `404 유지`가 기본입니다. (`200 + meta refresh` 금지)
- `tags` 필드는 작성 금지입니다. (`categories`만 사용)

## 1단계: 콘텐츠 구조 준비

- `content/posts/[slug]/index.md` (Page Bundle) 구조를 사용합니다.
- 이미지는 모두 해당 포스트 폴더 안에 둡니다.
- 프런트매터 기본 필드: `title`, `date`, `description`, `keywords`, `categories`, `cover`.

## 2단계: SERP 메타 가이드 적용

SERP 노출은 글자 수가 아니라 픽셀 폭 기준으로 잘리므로, 아래 권장값을 사용합니다.

- `title` 권장: 한글 기준 18~32자 (최대 40자)
- `description` 권장: 한글 기준 70~95자 (최대 120자)
- `keywords`: `마이요트`, `제부도요트`를 1~2순위에 배치
- 금지: `tags:` 필드, 과도한 키워드 반복, 제목/설명 완전 중복

## 3단계: 자동 사전점검 (필수)

배포 전 아래 명령을 먼저 실행합니다.

```powershell
.\scripts\seo-preflight.ps1 -BaseUrl https://myyacht.kr
```

점검 항목:
- 포스트 front matter `tags:` 잔재
- 소스/생성물 `localhost` 잔재
- `hugo` 검증 빌드
- `public/tags` 생성 여부
- `sitemap.xml` 내 `/tags/` 포함 여부
- 레거시 경로 404 유지 여부

실패 시: 배포 중단 후 원인 수정 → 재실행

## 4단계: 리뷰와 배포

- 초안은 선장님 확인 후 수정합니다.
- 로컬 프리뷰 필요 시 `hugo server`로 확인합니다.
- 배포는 반드시 SafeShip으로 실행합니다.

```powershell
.\scripts\safeship.ps1 -Message "post: [slug] SEO publish"
```

## 5단계: 배포 후 후속조치

- 라이브 핵심 URL 상태를 확인합니다. (`/`, `/posts/`, 수정 포스트 URL)
- 네이버 서치어드바이저: 변경 URL만 수집/제외 요청
- 구글 서치콘솔: 수정 URL에 "색인 생성 요청"
