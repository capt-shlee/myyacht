# 콘텐츠 공동 기획 및 초안 생성 워크플로우

선장님이 "글 쓰자"라고 말하면 아래 순서로 진행합니다.

## 1단계: 검색 의도와 키워드 확정

- 핵심 검색어 1개 + 보조 검색어 2~3개를 정합니다.
- 브랜드 키워드(`마이요트`, `제부도요트`)를 포함합니다.
- 의도 분류를 먼저 정합니다.
  - 정보형: 물때/준비물/안전/가이드
  - 비교형: 코스 비교/시간대 비교
  - 전환형: 예약/요금/문의

## 2단계: 포스트 구조 설계

- 제목 초안 2개를 만들고, 클릭 의도와 정보 명확성을 비교합니다.
- 문단 구조는 `문제 제기 -> 해결 정보 -> 실행 가이드 -> CTA`로 구성합니다.
- 하단에 "### 📚 함께 읽으면 좋은 글" 내부 링크 2~3개를 계획합니다.

## 3단계: SERP 메타 초안 작성

- `title` 권장: 한글 18~32자 (최대 40자)
- `description` 권장: 한글 70~95자 (최대 120자)
- `description` 1문장 안에 핵심 검색어를 1회 포함합니다.
- 제목/설명이 서로 같은 문장으로 중복되지 않게 작성합니다.

## 4단계: 프런트매터 템플릿 적용

```yaml
---
title: ""
date: 2026-01-01T09:00:00+09:00
description: ""
keywords:
  - "마이요트"
  - "제부도요트"
  - "핵심키워드"
categories:
  - "카테고리-1"
cover:
  image: "featured.png"
  alt: "핵심키워드 + 장면 묘사"
  caption: "클릭을 유도하는 한 줄"
---
```

- `tags:` 필드는 절대 추가하지 않습니다.
- 카테고리는 1~2개만 사용합니다. (과분류 금지)

## 5단계: 초안 전달 및 발행 연결

- 선장님 검토 후 수정사항 반영
- 발행 단계에서는 `수항사-게시글발행.md`로 넘어가 자동 사전점검 실행
